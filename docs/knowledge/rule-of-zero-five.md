# Rule of Zero / Five 与特殊成员函数

以 C++17 为基准。07 练习实现了独占动态数组的五个特殊成员函数，以及只保存 `std::vector<int>` 的 Rule of Zero 类。下文的 `= default`、禁用复制和 fd 设计是扩展参考，不代表已在 07 练习中实现。相关头文件随成员类型而定：vector 用 `<vector>`，`std::move` 用 `<utility>`，`std::size_t` 用 `<cstddef>`；`new[]` / `delete[]` 是 C++ 语言操作符，不是标准库容器接口。

## 两种设计

| 设计 | 资源所有者 | 复制与移动 | 适用场景 |
| --- | --- | --- | --- |
| Rule of Zero | `std::vector`、`std::string`、智能指针等 RAII 成员 | 尽量不声明析构、拷贝和移动函数；由成员能力决定生成结果 | 成员已经表达正确的所有权与复制语义 |
| Rule of Five | 类自身的裸资源句柄 | 一起审视析构、拷贝构造、拷贝赋值、移动构造、移动赋值；不合适的操作可删除 | 必须自行定义资源释放、复制或转移语义 |

Rule of Five 是设计检查，不表示五个函数都必须有用户提供的函数体。对于独占 fd，复制一个整数不会产生独立所有权，通常应 `= delete` 拷贝操作；若确需复制，应显式调用 `dup` 一类 POSIX 接口并处理失败。`dup` 属于 POSIX，不是 C++ 标准库。对普通非资源类也没有理由为了符合“五”而手写函数。

## 特殊成员函数及生成规则

| 函数 | 常见签名 | 作用与结果 |
| --- | --- | --- |
| 析构 | `~T()` | 对象结束时释放自身直接拥有的资源；成员随后自动析构；无返回值 |
| 拷贝构造 | `T(const T&)` | 从已有对象创建新对象；可复制资源类应提供独立所有权 |
| 拷贝赋值 | `T& operator=(const T&)` | 改变已存在的目标；要处理旧资源、自赋值与异常；返回目标引用 |
| 移动构造 | `T(T&&) noexcept` | 从可移动来源创建新对象，并使来源保持可析构的有效状态 |
| 移动赋值 | `T& operator=(T&&) noexcept` | 替换目标旧状态，接管来源；考虑自移动；返回目标引用 |

用户声明析构函数、拷贝构造函数或拷贝赋值函数会抑制隐式移动构造和移动赋值的声明。写 `std::move(x)` 只是把表达式转成可匹配移动重载的形式；没有移动重载时，仍可能调用 `const T&` 拷贝。用户声明移动操作后，隐式复制操作可能被定义为已删除，不能依赖“编译器会补齐其余四个”。如果确实希望某个特殊成员执行逐成员默认行为，可在合适位置写 `= default`；如果不允许该操作，用 `= delete` 明确表达。显式默认化的函数是否被删除、是否为 `noexcept`，仍取决于各成员和基类的能力。

```cpp
#include <cstddef>
#include <vector>

class Buffer {
public:
    explicit Buffer(std::size_t n) : data_(n) {}
    std::size_t size() const { return data_.size(); }

private:
    std::vector<int> data_; // 管理存储，类本身不用写五个特殊成员函数
};
```

`data_(n)` 调用 vector 的计数构造函数，生成 n 个零值 `int`；`data_{n}` 会优先选择初始化列表构造，生成一个值为 n 的元素。vector 的复制创建独立元素，移动后的来源有效但状态通常未指定；详见 [vector 专题](vector.md)。

## 生命周期与异常安全

拥有 `new[]` 数组的类必须用 `delete[]` 配对释放；`delete[] nullptr` 安全。拷贝赋值通常先分配并复制新资源，全部成功后才释放目标旧资源并提交新状态。对 `int` 数组，这样可以在分配失败时保持目标原值，提供强异常保证；若元素复制本身可能抛异常，还必须保证半成品资源也能被清理。自赋值检查可避免从已经释放的来源读取。

移动赋值要先处理目标原资源，然后接管来源并让来源可安全析构。07 练习的裸数组移动只交换几个标量状态，时间和额外空间均为 O(1)，因此可以真实承诺 `noexcept`。如果 `noexcept` 函数内部的异常逃出，程序会调用 `std::terminate`。vector 复制一般为 O(n)，可能因分配或元素复制失败而抛异常；移动成本和异常保证还取决于具体操作与分配器，不能一概写成 O(1)。

自定义 `at(index)` 的边界行为取决于该类的契约：07 练习约定调用者传有效下标，因此直接返回元素引用。引用不延长资源寿命；不能把 `-1` 等临时值作为 `int&` / `const int&` 的错误哨兵返回。需要检查下标时，可抛异常，或重新设计返回类型。标准库 `std::vector::at()` 会在越界时抛 `std::out_of_range`，与本项目的自定义方法不同。

更多引用绑定、`std::move` 与 `noexcept` 用法见 [引用与移动语义](move-semantics.md)；独占 fd 的 `get`、`release`、`reset` 约定见 [04 练习笔记](../learning-notes.md#04--raii-与文件描述符所有权)。
