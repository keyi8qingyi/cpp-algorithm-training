## 如何维护

每个专题先解释用途，再整理常见接口或语法：头文件、参数和重载、返回值、所有权与生命周期、失效条件、错误处理、必要的复杂度，以及能独立理解的短示例。项目自定义方法应明确标注，不能当作标准库接口推广。

每日完成练习后，把实际踩坑和验证结果写入学习笔记，再扩充相关专题并相互链接。专题中的扩展内容是查阅资料，不据此标记某阶段已掌握；涉及更高 C++ 版本的用法须明确注明。示例用于说明接口，不提前提供未完成算法题的解法。
